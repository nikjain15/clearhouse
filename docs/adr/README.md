# Architecture decision records

Each ADR records one decision in the form Build OS asks for: what was picked, what was rejected and
why, the trade-off accepted, and what would make us reverse it.

**Provenance.** These were reconstructed on 2026-08-28 from `docs/STRATEGY.md` §1 "Locked decisions",
`docs/PLATFORM.md`, `docs/UNDERWRITING.md`, and the code — not written at the time the decisions were
made. **Decision** and **Rejected** are quoted or paraphrased from those documents and are reliable.
**Reversal trigger** is marked `[inferred]` wherever the source documents state a decision without
stating what would undo it; those lines need your confirmation.
